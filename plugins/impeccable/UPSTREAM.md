The skill tree is an unchanged, self-contained snapshot. UPSTREAM.json records
every file hash; the package smoke rejects drift. Host manifests are the thin
atebites wrapper. No hook manifest, agent entrypoint or MCP server is registered.
Optional upstream commands can still request their own tools when invoked.

The template's deterministic detector remains its separately locked npm CLI;
installing this guidance does not replace that gate or waive any findings.
Updating the snapshot requires a reviewed upstream pin, refreshed hash inventory
and package smoke. Catalog/schema/context-loader proof is not every command's
live activation on every host.
